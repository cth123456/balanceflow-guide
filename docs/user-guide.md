# 衡动完整使用手册

[返回首页](../README.md) · [AI 配置](ai-setup.md) · [训练库转换](exercise-library-conversion.md)

本文按 App 中的实际操作编写。第一次配置先看首页路线；某个步骤没有对应按钮时，先到“设置 → 关于衡动”核对版本。

## 健康权限与同步

### 首次授权

1. 打开“设置 → 健康同步与诊断”。
2. 在“Apple 健康”一栏点连接按钮，按系统提示选择读取、写入权限。
3. 返回衡动，展开“同步状态与历史”查看反馈。

读取用于显示已有活动、心率、睡眠和身体等信息；写入用于把衡动记录同步到 Apple 健康。两者分别受系统权限控制。不愿授权的项目可不开放，但对应功能会缺少依据。

### 已授权但数据仍然空白

按顺序检查，不要立即重装：

1. 先在 iPhone“健康”App 找到同一日期、同一种指标，确认确实有数据。
2. 在健康 App 的个人资料/共享权限中找到衡动，检查相应读取或写入权限。iOS 版本不同，菜单名称可能不同。
3. 回到衡动，确认看的日期相同，等待同步完成。
4. 旧数据未出现时，在“同步状态与历史”点“后台扫描全部健康历史”，观察进度。
5. 衡动已有记录没写出时，点“同步未完成记录”。

“同步未完成记录”与“扫描全部历史”用途不同；前者重试写入，后者扫描健康数据。不要通过重新手动添加同一条记录来代替同步。

**完成标准：** 有来源的指标出现，或能从反馈知道缺少哪项权限/样本。健康数据不是一授权就自动生成；未戴手表的时段没有实测心率也属正常。

## 每日目标怎么设置

1. 在“设置 → 每日目标”点一个目标值。
2. 调整并保存，再依次检查剩余目标。
3. “目标依据与建议”可以展开查看调整依据。
4. 决定是否开启“复盘时自动更新当日目标”。希望自己控制数值时，先关闭该开关。

摄入累计来自已保存餐食；目标是计划值，修改目标不会自动修改餐食。历史复盘有自己的日期与依据，不要把今天的目标变更当作所有历史评分都会立即重算。

## 记录饮食

### 不用 AI 的手动记录

1. 打开“饮食”，确认正在记录的日期。
2. 点右上角 **“+ / 手动添加”**。
3. 按表单选择食物、填写份量和时间等信息。
4. 核对营养后保存，回列表确认这餐已出现。

适合已知重量、包装标签明确，或暂时不想配置 AI 的情况。

### 用文字、照片或录音记一餐

1. 先按 [AI 配置教程](ai-setup.md) 配好所需能力。
2. 打开“饮食”，点右上角 **AI 拍照、文字或语音记餐**入口。
3. 选择输入方式：文字描述、录音、拍照或相册。
4. 附上实际吃下的份量信息，再开始识别。
5. 检查食物是否重复、份量是否合理、是否扣除了剩余部分，修改后保存。
6. 回当天列表，核对整餐摘要和摄入累计。

**实用描述：**

| 实际情况 | 可以怎样写 |
| --- | --- |
| 已称重 | “午餐熟米饭 150 克，熟鸡胸肉 120 克” |
| 只有生活单位 | “一小碗米饭、一份番茄炒蛋、一个鸡蛋” |
| 有剩余 | “这份饭只吃一半，鸡腿吃完，骨头没吃” |
| 多张图片 | “图 1 餐前，图 2 吃完剩余，图 3 是图 1 的另一角度” |
| 共享菜 | “这盘三人分，我大约吃三分之一” |

AI 估算不能知道所有调料、用油或真实重量。包装食品优先对照营养标签；份量越模糊，结果越需要核对。

### 保存后发现有误

点开整餐查看详情，在 **编辑餐食** 中核对和修改；整餐误录时使用 **删除整餐**并确认。先检查当前列表，不要直接重新识别保存，否则可能重复累计。

AI 教练也可以对已有餐食提出估算调整，但必须明确是哪一餐，并检查修改建议。

## Siri 后台记餐

适用于包含“后台语音记餐”快捷操作的版本。Siri 用系统语音入口，不等于 App 内录音。

1. 安装后打开一次衡动，先确保 AI 文字接口可用。
2. 呼出 Siri，先说 **“用衡动记餐”**。
3. 等系统追问 **“你吃了什么？”**，再说食物、份量和餐次，例如“今天午餐一碗米饭、两个鸡蛋”。
4. 听清返回的是“已记录”还是“已保存，稍后识别”。
5. 回衡动饮食页检查结果和日期。

不要依赖一句话“用衡动记录 + 时间 + 全部食物”把后半句直接传入；优先按“唤起 → 等追问 → 回答”的两步方式使用。

提示稍后识别时，原文可能已进入队列。恢复网络、打开衡动后查看处理结果，不要反复对同一餐再次录入。

没有识别出 App 名称时，可在“快捷指令”App 中搜索衡动的“后台语音记餐”操作，先从那里运行一次。若仍不可用，反馈 App/iOS 版本和 Siri 实际回复。

## 记录训练

### 手动添加一项训练

1. 打开“训练”，确认日期。
2. 点 **添加训练**，在动作库搜索动作。
3. 打开动作教程核对名称、器械和做法，不只看缩略图。
4. 填写时间、组数、次数/秒数、重量、时长和主观强度等表单项目；按动作类型核对单位。
5. 点“保存”，回训练列表检查。

次数类动作按组与次数记录；静态拉伸可能按秒，有氧以时长为主。自重/拉伸无需为了填满表单而添加负重。建议值只是起点，实际重量要按个人情况调整。

**保存记录与开始实测不同：** 仅填写一个计划或手动保存，不代表 Watch 已开始训练会话。要实时计时和采样，需确认页面/Watch 已进入记录状态。

### 按 AI 当日计划训练

1. 在“训练 → AI 当日计划”查看当天安排，或在“AI 计划”查看对应日期。
2. 核对动作、器械、组次、重量、时长和休息安排。
3. 按计划逐项记录、更新完成情况。
4. 结束后核对列表与计划进度；没有执行的动作不要标作完成。

对计划不满意，可在 AI 教练说明时间、器械限制或替换需求，核对建议后应用。完全休息日可以没有训练；训练为 0 时，要区分明确休息、没有采样和漏记，不要仅为补齐图表虚构训练。

## Apple Watch 使用

1. 在 iPhone 的 Watch App 中确认衡动的手表端已经安装。
2. 打开衡动 Watch，按提示完成需要的健康权限。
3. 确认 iPhone 与 Watch 正常配对连接。
4. 从 Watch 的“快速开始”选择动作、核对目标，点“开始训练”；从 iPhone 发起时，也要看 Watch 是否实际进入记录界面。
5. 训练中按需暂停、继续；结束用完成/结束控件。
6. 返回 iPhone 检查训练记录、时长与同步结果。

深蹲计数支持的流程中，结束后 Watch 会显示次数、加减按钮和环形倒计时；可调整次数后立即确认，也可等待倒计时采用当前值。不是所有动作都支持自动计数，实际次数仍需核对。

没有心率或计时：先确认会话是否启动，再查连接与健康授权。手动录入的记录不等于 Watch 实测。取消训练会放弃本次会话，不要把“取消”当“保存并结束”。

图标更新后仍显示旧图，可先重开手表端、必要时重启 Watch；不要以删除手机 App 作为第一步，先备份数据。

## 个人偏好、器械和 AI 教练

### 让计划知道你的条件

在 **AI 计划**中的身体/个人信息区域找到 **个性标签 → 管理**，保存需要长期参考的习惯、限制和偏好；在 **健身房器械**区域补充实际可用器械。

例子：“只有哑铃和长凳”“每次 30 分钟”“不推荐含奶餐食”。记录完成后，再让教练按这些条件调整计划。没有在动作库中可匹配的动作，不应靠改名字强行视为已经导入。

### 对话到修改记录的完整顺序

1. 进入 **AI 教练**，说明日期、对象和预期；例如“把今天午餐米饭从整碗改成半碗”。
2. 需要图片时选择合适照片，避免发送无关个人信息。
3. 等待回复，区分普通解释与可执行的修改建议。
4. 逐项核对修改对象、数值、日期，再确认应用。
5. 返回饮食、训练或目标页面，确认对应数据真的更新。

在教练右上角 **“…”** 可以开关“当日训练计划”“餐食营养估算”“训练量与消耗估算”“饮食推荐范围”“总结与评分”“每日营养目标”等建议权限。被关闭的范围不能仅靠一句聊天指令就当作已修改。

当前对话只加载当天最近 30 条。这里不是永久聊天记录库，也不会自动同步到 ChatGPT 或 Muse 的聊天列表。重要结论请另存。

## 自动复盘和评分

1. 在“设置 → 自动复盘、计划与评分”决定是否开启“每天自动复盘并生成次日计划”。
2. 展开“执行时间与状态”，选择计划时间并查看最近完成情况。
3. 复盘前尽量补齐餐食、训练与健康数据，再在“AI 计划”查看对应日期的结果。
4. 需要校核旧评分时，展开“选择范围并校核”，选日期后执行，查看反馈。

自动任务依赖 AI 配置、网络、权限和 iOS 后台调度，不能保证设定分钟准点运行。未完成时先看状态与错误，再重试，不能把未生成的内容当作已有计划。

“复盘时自动更新当日目标”是另一个开关。只想看分析、不想自动改目标，可以关闭它。

## 添加小组件

1. 长按 iPhone 主屏空白处进入编辑，打开添加小组件入口。
2. 搜索“衡动”，选择对应组件及尺寸，添加到桌面。
3. 首次添加后打开衡动一次，确认有当天目标和记录。

| 小组件 | 用途 | 看不到内容时 |
| --- | --- | --- |
| 快速记餐 | 查看当前摄入/计划热量，进入拍照或语音记餐 | 检查今日目标和饮食是否已保存 |
| 今日训练计划（中号） | 查看动作、组数和完成进度 | 在 App 中确认当天已生成计划 |
| 昨日复盘 | 查看前一天评分、摄入、训练摘要 | 查看昨日复盘是否真正生成 |

小组件由系统安排刷新，不是每秒变化。先打开 App 核对日期和记录，再等刷新。

## 备份与恢复

### 建立备份

设置 → 备份与恢复 → 备份选项 → 选择备份文件夹 → 设置每周日期和时间 → 立即生成完整备份。

确认最近备份时间，并在“文件”App 检查目标文件夹。自动备份可能在系统允许的稍后执行；App 当时没运行时会在下次打开补做。备份数量有限，不要依赖它永久保存每个历史版本。

### 换机恢复

1. 在旧手机先生成备份，确认文件确实可在可信位置访问。
2. 新手机安装并打开衡动，进入同一备份设置。
3. 点“选择已有备份并恢复”，选择衡动生成的 JSON 备份。
4. 阅读预览，确认要恢复的内容，点“合并恢复”。
5. 核对餐食、训练、目标、AI 配置和训练库；新设备的 Apple 健康授权、麦克风等系统权限需要单独检查。

恢复补充缺失记录，不会先清空当前数据；不要假设它会用旧文件覆盖一切。同一 ID 的现有记录不等于会被备份强制重写。

**完整备份与训练库 JSON 是两种文件。** 备份导入走“选择已有备份并恢复”，动作索引导入走“训练资源”的 HTTPS 链接。两者不能互换。

完整备份含密钥和个人记录。iCloud 文件夹备份不等于实时同步；不要多人共用备份，更不要上传公开仓库。

## 反馈前准备什么

按这个模板说明，通常比“不能用”更容易定位：

```text
App 版本/构建号：设置 → 关于衡动
iOS / watchOS 版本：
出问题的入口：例如 设置 → AI 接口 → 测试文字分析连接
操作：先……，再……
预期：
实际结果/错误原文：
是否每次出现：
是否影响文字、图片、语音中的某一种：
```

日志入口：**设置 → 关于衡动 → 导出脱敏诊断日志**，生成后按界面提示分享。发送前仍应检查附件内容，遮去截图中的密钥、个人记录和其他无关信息。

不要提交完整备份、密钥、服务商登录密码或整个健康数据导出。密钥泄露时在服务商控制台撤销，单纯删除截图不能撤销凭证。
