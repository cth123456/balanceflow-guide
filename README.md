> 第一次使用，先完成下面的路线。不用先转换训练库，也不用先买 Apple Watch。AI 功能需要自行配置服务商 API 密钥；普通聊天账号的密码不能填进密钥栏。

## 先弄清楚四个页面

| 底部页面 | 在这里做什么 | 第一次先做哪一步 |
| --- | --- | --- |
| AI 计划 | 查看选中日期的状态、复盘与计划，进入 AI 教练，管理个人偏好与器械信息 | 确认日期，查看已有记录 |

## 第一次使用路线

### 第一步：安装后打开一次 App

使用 TestFlight 时，先在 iPhone 安装 Apple 的 TestFlight，再打开上面的测试入口，按页面提示加入并安装。测试名额和构建有效期以 TestFlight 页面为准。

首次打开后，检查是否能进入“饮食”“训练”“设置”。暂时不配置 AI，也可以使用基础记录功能。

### 第二步：连接 Apple 健康

1. 打开衡动 **设置 → 健康同步与诊断**。
2. 在“Apple 健康”一栏点连接按钮，按系统提示选择愿意允许的读取和写入项目。
3. 返回衡动，展开 **同步状态与历史** 查看同步信息。
4. 已有记录没写入健康时，用“同步未完成记录”；补查更早的数据时，用“后台扫描全部健康历史”。

**完成标准：** 授权流程结束，返回 App 后没有持续的同步错误。授权不代表每项都有数值；睡眠、心率等还需要健康 App 中确实存在对应样本。

不想连接健康，可以先跳过；基础手动记录仍可使用。详见[健康权限排查](docs/user-guide.md#健康权限与同步)。

### 第三步：检查每日目标

1. 打开 **设置 → 每日目标**。
2. 逐一点按热量、蛋白质、碳水和脂肪数值，调整并保存。
3. 刚开始先核对手动目标；理解复盘效果后，再决定是否开启“复盘时自动更新当日目标”。

**完成标准：** 四项数值是你打算使用的目标。热量单位为千卡，三大营养素单位为克；“计划热量”是目标，“已摄入”是饮食记录的累计值。

### 第四步：需要 AI 时再配置

1. 打开 **设置 → AI 接口**。
2. 在 **接口平台** 选择你已有 API 账户的服务商。
3. 在 **API 密钥** 粘贴该平台生成的密钥。
4. 点 **保存密钥并自动配置**；已有密钥时按钮显示“替换密钥并补齐模型”。
5. 点 **测试文字分析连接**，查看结果。
6. 文字测试通过后，到饮食页试一次图片识别；需要录音时，再单独试语音。

**完成标准：** 文字测试成功，且你需要的图片或语音功能分别成功。**文字成功不等于图片、语音也配置好了。**

不知道密钥是什么、地址怎么填、选什么接口格式？照[AI 配置教程](docs/ai-setup.md)操作，里面有字段解释和逐项排错表。

### 第五步：先用内置训练库

打开 **设置 → 训练资源 → 接入训练库详细信息**，把“当前动作库”设为 **内置基础动作库**。去“训练”页搜索一个动作，打开教程、添加一条训练。

**完成标准：** 能搜索动作并保存训练记录。远程库是可选扩展，先不用配置。

使用自己的动作、图片或视频时，再看[训练库转换与导入教程](docs/exercise-library-conversion.md)：原始 JSON → 转换 → 发布链接 → App 内导入 → 检查结果。

### 第六步：做第一份备份

1. 打开 **设置 → 备份与恢复 → 备份选项**。
2. 点 **选择备份文件夹**，选择自己控制的文件夹，例如 iCloud Drive 中的专用文件夹。
3. 点 **立即生成完整备份**。
4. 查看“最近备份”时间和反馈，再到“文件”App 确认文件已生成。

**完整备份含 API 密钥、身体数据和记录，不要发到公开仓库、Issue 或公开网盘。** 选择 iCloud 文件夹是备份，不等于多设备实时同步。

## 每天照着这样用

| 时间 | 操作 | 操作后检查 |
| --- | --- | --- |
| 吃完一餐 | 饮食页记餐，核对食物、份量和营养后保存 | 当天列表有这一餐，摄入累计增加 |
| 训练前 | 训练页查看当天计划，核对动作、组次和重量 | 计划符合可用器械和实际情况 |
| 训练中 | 按页面或 Watch 控件开始、暂停、结束 | 是否真的开始计时；有实测来源时再看心率 |
| 训练后 | 保存记录，核对完成情况与时长 | 日期正确，没有重复记录同一次训练 |
| 晚上 | 在 AI 计划查看当天复盘和下一天安排 | 数据完整，分清休息日与漏记 |

记餐例子：“午餐一碗熟米饭、一份番茄炒蛋，吃完了。”有照片时再注明：“第一张餐前，第二张剩余。”不要把同一餐用文字、照片、Siri 各保存一次。

AI 教练可以这样问：

- “今天只有 30 分钟，把当日计划调整成哑铃训练。”
- “这份午餐只吃了一半，请调整已有餐食的估算。”
- “解释今天评分扣分的原因，先不要修改目标。”

需要修改数据时，核对建议并确认应用；只是聊天回答不代表记录已经更新。详细步骤见[使用手册](docs/user-guide.md)。

## 使用边界

- AI 营养、热量和训练建议都是估算，保存前需要核对。衡动用于日常记录，不替代医疗诊断或治疗。
- 实测心率、活动能量和路线依赖设备、授权和实际采样；没有样本时不能当作已测得。
- 当前 AI 教练对话仅加载当天最近 30 条，不是永久聊天档案。重要结论请另行保存。
- 自动复盘、备份和小组件刷新受 iOS 调度影响，不保证在设定分钟准点执行。
- 本仓库目前为私有仓库，教程及仓库内文件仅有权限的访客可访问；这与单独公开的 TestFlight 测试入口不同。

反馈问题请附 App 版本、具体操作、预期和实际结果。需要日志时，在 App **设置 → 关于衡动 → 导出脱敏诊断日志**中生成；不要上传完整备份或密钥。
